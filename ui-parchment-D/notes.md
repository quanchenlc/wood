## 客户端必须实现（清晰度和规格）
1. **HUD 按设备 dpr 渲染。** 3D 层可以单独 ≤1.5x 渲染到 RT 再放大，但 HUD 面尺寸 = 绘图缓冲尺寸，1:1，不做二次重采样（见 ui-parchment-v2 notes §3）。
2. **叠加材质 `toneMapped = false`**，并设置 premultipliedAlpha。
3. **字号按 pt 写**（canvas 已经按 dpr 缩放过），不要再乘 750 比例。全站最小 11pt。
4. **9-slice 的源和目标分开：**
   - 源 insets 用实际加载那个 variant 的 px（@2x = pt×2，@3x = pt×3）；目标 insets 用 `nine_slice_insets_pt`。
   - 所有 dx/dy/dw/dh 先对齐设备像素：`snap = v => Math.round(v*dpr)/dpr`。
   - 整块图标的绘制尺寸直接用 `logical_size`。
5. **tag_* 切片有 4pt 透明边加投影：** 按 104×40 绘制在「视觉框 −4pt」的位置，`visual_pad_pt=4`。
6. **抽屉：** drawer_vellum 按最终尺寸画，再加裁切矩形。roll_paper 是 3-slice，端头宽度跟着直径缩放。roll_shadow 横向拉伸。详见 interaction.md §5。
7. **好友柴榜** 的列表行在开放数据域（sharedCanvas）里画，sharedCanvas 也要按 dpr 建，否则又会糊。
8. **触摸路由：** 抽屉、小签、面板优先吃掉事件；只有 UI 没有命中时，才把 pointer 事件交给 3D（劈砍：pointerup 且位移 ≤6px；水平拖动转视角）。
9. **存储键：** `fw_guide_v1`（引导完成或跳过）、`fw_style`（当前风格）。
