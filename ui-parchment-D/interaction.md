# D_fix_v2 · 交互说明（竖屏 375×812 / 横屏 812×375，单位 pt / ms）

胶囊位置一律运行时取 `wx.getMenuButtonBoundingClientRect()`。下文竖屏 (281,48)–(368,80)、横屏 (718,18)–(805,50) 仅为 iPhone X 档示例。

## 0. 纸面合成（相对 D_final 的变更）

**禁止**再对纸身使用 `drawer_vellum` 九宫格。

每帧绘制顺序：
1. 遮罩（打开约 30%）。
2. 纸身：`paper_tile` cover（竖屏）或 tile（横屏）填满矩形；展开中用裁切矩形 `[0,0,screenW,clipH]`。
3. `tear_edge`：y ≈ paperBottom − 10，高度 32pt，宽度 = 纸身宽；源 insets_pt `[48,0,48,0]`，只拉左右。
4. `roll_paper` / `roll_shadow`：滚筒中心 y = clipH（与 D_final §5 相同）；p≥0.93 开始淡出。
5. 内容层（α 与 translateY 同 D_final）。
6. 小签挂在撕口/滚筒下沿。

动效时长与曲线沿用 D_final：开 350ms / 收 250ms。撕口带高度由旧 44pt inset 改为独立条 **32pt**；关键帧仍见 `motion/`（100% 边以撕口下沿为准）。

下拉手势仍**只从小签热区开始**，避免与微信下拉冲突。

## 2. 打开 / 收起
同 D_final：点小签或从小签热区下拉打开；点遮罩 / 上推 / 再点小签收起。  
**变更：** 点「好友柴榜」**不再收起抽屉**，改为内页翻页（见 §7）。点「看短片」「玩法」仍可先收起再执行（或按产品保留抽屉，由客户端定；美术默认：短片/玩法可盖在抽屉上或先收起）。

## 3. 红点
同 D_final：柴棚可领或加速有次数时亮；打开抽屉清除；用尽/引导/面板期间不显示。

## 4. 树根用尽
- 日配额用尽：文案「明天 0 点恢复」；小签 `tag_madder`「树根用尽」。
- 临时无根（生长中）：显示生长倒计时（统计列或气泡）。
- 面板仍用 `panel_vellum`（弹层，非抽屉）。免费领取在广告前。

## 5. 卷开动效
见 D_final interaction §5 与 `motion/`。仅纸面采样改为 paper_tile+tear；clipH / roll / 曲线不变。

## 6. 抽屉内页：风格
同 D_final §6。入口**只有**「风格：羊皮纸 〉」行（无圆钮）。翻页 200ms。

## 7. 抽屉内页：好友柴榜（替换旧弹层）
- 点「好友柴榜」：内容层翻页 200ms（cubic-bezier(0.3,0,0.2,1)），**纸面不收起、不加第二层 dim**。
- 顶栏：「‹ 返回」+ 标题「好友柴榜」。返回或右滑回首页。
- 列表在开放数据域 `sharedCanvas`：创建宽高 = 布局 pt × 设备 dpr；嵌在抽屉内容裁切区内，可滚动。
- 横屏：双列排布，避胶囊。
- 抽屉收起后再开：回到首页。
- **废弃** D_final `spec/e_rank` 弹层流程。
