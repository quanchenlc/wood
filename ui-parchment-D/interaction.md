# D_fix_v3 · 交互说明（竖屏 375×812 / 横屏 812×375，单位 pt / ms）

胶囊位置一律运行时取 `wx.getMenuButtonBoundingClientRect()`。下文竖屏 (281,48)–(368,80)、横屏 (718,18)–(805,50) 仅为 iPhone X 档示例。

## 0. 纸面合成（v3，替换 v2 §0）

**禁止**对纸身做九宫格、cover 或按抽屉高度缩放。

每帧绘制顺序：
1. 遮罩（打开约 30%）。
2. 纸身：`paper_tile` **只平铺**，1 texel = 1 设备像素（@2x 512px / @3x 768px，都是 256pt 一格），从抽屉原点开始重复。展开时只改裁切矩形 `[0,0,screenW,clipH]`，纸纹不缩放、不游动。
3. `tear_edge`：**tear_top = paperBottom − 16pt**（v2 是 −10）。原因：顶部 14pt 是 alpha 渐隐，必须整段盖在纸上，否则会透出 3D 场景。高度固定 32pt，宽 = 纸身宽；源 insets_pt `[48,0,48,0]`，只拉左右，中段 stretch（纸纹已经预拉宽，竖屏压缩 0.39× 后仍然自然）。阴影已经烘焙在条内（齿口下方约 3pt），**不要再额外加投影**。
4. `roll_paper` / `roll_shadow`：滚筒中心 y = clipH；p≥0.93 开始淡出。
5. 内容层。
6. 小签挂在撕口下沿：tag_top = tear_bottom。

撕口下沿位置：
- 竖屏首页：400pt。
- 竖屏柴榜页：600pt（对齐 0.3.6 加高页）。
- 横屏：`windowHeight − safeArea 底部 − 32 − 4`，iPhone X 为 375 − 21 − 36 = **318pt**；小签在 318–350pt。

## 2. 打开 / 收起
同 D_final：点小签或从小签热区下拉打开；点遮罩 / 上推 / 再点小签收起。  
**变更：** 点「好友柴榜」**不再收起抽屉**，改为内页翻页（见 §7）。点「看短片」「玩法」仍可先收起再执行（或按产品保留抽屉，由客户端定；美术默认：短片/玩法可盖在抽屉上或先收起）。

## 3. 红点
同 D_final：柴棚可领或加速有次数时亮；打开抽屉清除；用尽/引导/面板期间不显示。

## 4. 树根用尽
- 日配额用尽：文案「明天 0 点恢复」；小签 `tag_madder`「树根用尽」。
- 临时无根（生长中）：显示生长倒计时（统计列或气泡）。
- 面板仍用 `panel_vellum`（弹层，非抽屉）。免费领取在广告前。

## 5. 卷开动效
见 D_final interaction §5 与 `motion/`。仅纸面采样改为 paper_tile+tear；clipH / roll / 曲线不变。

## 6. 抽屉内页：风格
同 D_final §6。入口**只有**「风格：羊皮纸 〉」行（无圆钮）。翻页 200ms。

## 7. 抽屉内页：好友柴榜（v3 布局）
- 点「好友柴榜」：内容层翻页 200ms（cubic-bezier(0.3,0,0.2,1)），纸面不收起、不加第二层 dim。
- 顶栏：「‹ 返回」+ 标题「好友柴榜」。竖屏顶栏 top = 胶囊底 + 12（X 档 92pt；字顶 ≥94pt），中心 y106，标题线 y124。返回或右滑回首页。「‹ 返回」热区 ≥ 76×44pt。
- 列表在开放数据域 `sharedCanvas`：创建宽高 = **视口** pt × dpr。
- **视口**：竖屏 y132–500，行高 54；横屏 y66–212，双列，行高 40，列距 24。
- **渐隐**：视口上下各 16pt alpha 渐隐（在开放数据域里画，或在主域盖一条 paper_tile 采样加 alpha 渐变的条）。scrollTop=0 时顶部不渐隐，滚到底时底部不渐隐。禁止硬裁切到半行。
- **固定页脚「我」**：竖屏 y508–560（屏宽 −32），横屏 y218–270（内容宽 +16）。底图用 `row_self_highlight` 九宫格 [12,12,12,12]pt，或代码画 rgba(252,243,220,0.5)，6pt 圆角，1px rgba(110,80,45,0.32) 描边。**始终显示**（即使「我」已在视口内），避免布局跳动和底部留白。
- 分数统一「N 根」（竖屏、横屏一致）。名次 11pt Bold，名字和分数 14pt（横屏 13pt）。
- 抽屉收起后再打开：回到首页。
