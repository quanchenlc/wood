# D 抽屉 · 交互说明（375×812pt 基准，所有数值单位 pt / ms）

坐标原点在屏幕左上角。胶囊位置一律运行时取 `wx.getMenuButtonBoundingClientRect()`，下文的 (281,48)–(368,80) 只是 iPhone X 档的示例值。

## 1. 元素与命中区
| 元素 | 视觉 | 命中区 | 说明 |
|---|---|---|---|
| 顶部小签「余 N」 | 96×32，水平居中，y = 胶囊 top（48） | **128×48**（x 123.5–251.5，y 40–88） | 抽屉入口，常驻 |
| 抽屉（展开） | 0–400（撕边在 356–400） | 纸面内部 | 内容从 y≥94 开始排，即胶囊底 +14 |
| 小签（展开时） | 跟着纸边移动，top = 抽屉底 −16 = 384 | 128×48 | 箭头变成朝上 |
| 遮罩 | 30% #1e140a | 抽屉外的全屏区域 | 点击即收起 |

## 2. 打开与收起
- **打开：**
  - 轻点小签：pointerup 时位移 ≤6px，且时长 <300ms。
  - 也可以从小签热区里**开始**往下拉。
  - **下拉手势只在小签热区内开始时生效**，在其他位置往下滑一律不处理，这样不会和微信自己的下拉（返回 / 最近使用）抢手势。
  - 首次 touchstart 落在热区内时，记 `dragOwner = 'drawer'`。
- **下拉跟手：**
  - p = clamp(dy / 380, 0, 1)，直接驱动 §5 的画法（裁切高度、滚筒、小签都跟着 p 走）。
  - 跟手阶段内容透明度固定为 0。
  - 松手后：p > 0.35 或下拉速度 > 0.3 pt/ms，就从当前 p 播完打开动画；否则从当前 p 播收起动画。
- **收起，以下任意一种都可以：**
  - 点遮罩（抽屉外任意位置）。
  - 在纸面上往上推：dy < −24pt，或速度 > 0.3 pt/ms 往上。上推也是跟手的，规则和下拉对称。
  - 再点一次小签。
  - 点了会离开抽屉的入口：好友柴榜、看短片、玩法会先收起抽屉再执行；「风格」是抽屉内翻页，不收起。
- **劈砍隔离：**
  - 劈砍 = 在木头上 pointerup，位移 ≤6px；水平拖动 = 转视角。
  - 抽屉打开或动画进行中，所有触摸都由 UI 层吃掉，**不传给 CameraController / GameController**。
  - 收起动画开始的那一次点击（点遮罩）也不算劈砍。
  - 小签热区内的触摸也不传给 3D，即使是横向拖动。
- **广告、领取的结果回来时：** 抽屉保持打开，数字滚动更新（240ms）。领取成功后主钮短暂显示「已入柴棚 +40」，1.2s 后变成空态文案。

## 3. 红点规则
- **显示条件**（任一成立）：
  - 柴棚可领 > 0。
  - 看短片加速今天还有次数，且当前不在加速中。
- **清除：** 打开抽屉时清除，开始展开的那一帧就清。
- **重新出现：** 只在出现**新状态**时出现，比如柴棚从 0 变成 >0，或加速冷却结束、次数恢复。不会因为状态一直存在就反复亮。实现上记录 `lastSeenStateHash`，在打开抽屉时更新。
- **以下情况不显示：** 树根用尽时（小签换成用尽态）、引导期间、任何面板打开期间。
- **样式：** r=4.5，#8b2e2e，1.2pt 奶油描边。圆心在小签视觉框右上角内收 3pt。不显示数字。

## 4. 树根用尽时
1. 剩余变成 0 的那一刻：
   - 小签换成 `tag_madder`，文字「树根用尽 ⌄」，宽 112。
   - 轻脉冲两次：scale 1→1.06→1，每次 600ms，ease-in-out。之后静止。
2. **当天第一次**用尽：600ms 后自动弹出「树根用尽」面板（spec/c），每天只自动弹这一次。
3. 之后玩家再点木头（劈砍被拦下）：
   - 木头上方弹出气泡「今日蓄养中 · 00:50 后长出」，带小钮「▶ 看短片 +20 根」（spec/a2）。
   - 气泡淡入 160ms，停 6s 后淡出 240ms。
   - 点小钮直接拉起广告；点小签打开用尽面板。用尽时小签打开的是面板，不是抽屉。
4. 面板打开期间：
   - 小签压在 42% 遮罩下面，红点隐藏，抽屉不能打开。
   - 「领取」入口只保留面板里的「免费领取 柴棚 N 根」，N=0 时整行不出现。
5. 看完广告，或时间到了树根长回来：小签恢复 `tag_parchment`「余 N」，闪一下（亮度 +15%，200ms）。

## 5. 动效：羊皮纸展开 / 卷回（代码驱动，裁切 + 滚筒定位，无序列帧）
关键帧图：`motion/keyframes_strip.png`（0 / 30 / 60 / 100%）、`motion/kf_000.png … kf_100.png`、曲线图 `motion/curves_open.png`。数值由 `src/motion_math.py` 生成，客户端可以照抄。

### 5.1 用到的切片
- `drawer_vellum`：抽屉纸面，9-slice，只有底边是撕口。**始终按最终尺寸绘制**，绘制矩形 x=−28, y=−24, w=431, h=424，再用裁切矩形 `[0, 0, 375, clipH]` 裁掉下面的部分。纸面本身**不随动画拉伸**，纹理不会游动。
- `roll_paper`：滚筒，3-slice。直径为 d 时：
  - 整体高度画成 d；
  - 左右端头目标宽度 16·d/24；
  - 宽度 395（x −10 起），比屏幕略宽，端头只露出一半，像是纸从两侧卷进去。
- `roll_shadow`：滚筒下的投影。横向拉到 395，高 0.6·d，画在 y = rollY + 0.35·d，透明度 = 滚筒透明度。
- **为什么裁切边看不见：**
  - 裁切边始终在 y = clipH，滚筒中心也在 y = clipH，直径 ≥14，盖住了平直的裁切边。
  - 撕口带在纸面 356–400，只有 p > 0.89 时才进入可见区。这时滚筒已经开始淡出，所以**撕口只在接近 100% 时露出来**。
  - 如果客户端改了抽屉高度，保持「滚筒在 p≥0.93 时才开始淡出」，以及「撕口带 = 底部 44pt」这两条即可。

### 5.2 曲线
| 量 | 公式（p = 缓动后的进度 0→1） |
|---|---|
| 打开 | 350ms，`cubic-bezier(0.40, 0.30, 0.40, 1.00)`：起步稍慢（像纸先松开），中段快，尾段很长的减速 |
| 收起 | 250ms，`cubic-bezier(0.55, 0.00, 0.80, 0.35)`：ease-in，越卷越快 |
| 裁切高度 clipH | 20 + 380·p（0% 时露出顶部 20pt，被滚筒盖住） |
| 滚筒中心 rollY | = clipH |
| 滚筒直径 d | √(14² + (40² − 14²)·(1 − p))。**起始 40pt，结束 14pt**。按「剩余纸面积」缩小，前段缩得慢、后段缩得快，接近真实卷纸 |
| 滚筒透明度 | p < 0.93 时为 1，之后线性降到 0（p=1） |
| 小签 top | max(48, clipH − 16 + 1.25·(d − 14))：始终挂在滚筒下沿，压住 4pt，最后停在 384 |
| 遮罩 | 打开：0→30%，前 200ms 线性；收起：30%→0，250ms 线性 |
| 内容 | 打开：58% 处（203ms）开始，120ms 内 α 0→1（ease-out），同时 translateY 6→0；收起：0–80ms 先淡出 |
| 投影 | 纸面整体投影（shadowBlur 5pt，45%）随裁切一起走；滚筒投影见 5.1 |

关键帧数值（打开）：
| 时间 | p | clipH / rollY | d | 滚筒 α | 内容 α | 遮罩 | 小签 top |
|---|---|---|---|---|---|---|---|
| 0%（0ms） | 0.000 | 20 | 40.0 | 1.00 | 0.00 | 0% | 48 |
| 30%（105ms） | 0.386 | 167 | 32.5 | 1.00 | 0.00 | 16% | 174 |
| 60%（210ms） | 0.846 | 341 | 20.3 | 1.00 | 0.11 | 30% | 333 |
| 100%（350ms） | 1.000 | 400 | 14.0 | 0.00 | 1.00 | 30% | 384 |

### 5.3 收起（打开的逆过程）
- 0–80ms：内容 α 1→0，translateY 0→−4。
- 40–230ms（190ms）：p 从 1 降到 0，用收起曲线。p < 0.93 时滚筒重新淡入（α 规则同上），直径从 14 长回 40，向上卷。
- 遮罩 30%→0，在 250ms 内线性完成。
- 210–250ms：滚筒停在 y=20、直径 40，40ms 内淡出（α 1→0）；小签回到 y=48，同时恢复红点判定。总时长 250ms。

### 5.4 打断
- 动画中点击小签、遮罩，或上推 / 下拉：**从当前 p 反向播放**，不跳帧。
- 实现：维护线性时间进度 q 和方向。反向时，用新方向的曲线反解 q'，使 ease_new(q') = p_now（二分 20 次即可）。剩余时长 = 新方向总时长 × (1 − q')。
- 内容 α 也从当前值开始，按反向规则继续。
- 跟手拖动随时可以接管：用当前 p 作为起点，松手后按 §2 的规则决定往哪个方向播完。
- 动画进行中，抽屉内的按钮不响应（p < 1 时内容 α < 1），避免误点。

### 5.5 音效（可选，仅建议）
- 纸张沙沙声：打开 1 条（约 280ms）、收起 1 条（约 200ms）。单声道 mp3，22kHz 48kbps，**每条 <15KB**。
- 来源：自己录（揉旧信纸、羊皮纸卷），或用 CC0 素材（例如 freesound 上标 CC0 的 paper rustle），并在致谢里注明。
- 播放：`wx.createInnerAudioContext`，音量 0.35；静音设置下不播放。不要用版权音效库。

### 5.6 性能
- 每帧只有三件事：一次裁切、一次 9-slice、一次 3-slice。不用离屏序列帧，不用 shader。
- 内容层可以先缓存成一张 canvas，动画期间只改 globalAlpha。
- 只有动画进行中才重绘 HUD，静止时不重绘。

## 6. 抽屉第二页：风格
- 点「风格：羊皮纸 〉」或圆钮「风格」，内容层左移翻页，200ms，cubic-bezier(0.3,0,0.2,1)。纸面高度从 400 动到 420，用同一套裁切加滚筒（直径固定 14，不显示滚筒），时长 200ms。
- 点「〈」或右滑，回到第一页。抽屉收起后，下次打开回到第一页。
- 选中某套风格：勾立即移动到该行，后台切换场景；小签临时显示「切换中…」，切完恢复。抽屉不自动收起。存储键 `fw_style`。

## 7. 好友柴榜
- 点抽屉里的「好友柴榜」：抽屉先按 §5.3 卷起（250ms），再弹出面板（200ms 淡入，scale 0.96→1）。面板遮罩 42%。
- 列表行在开放数据域里绘制（sharedCanvas 也要按 dpr 建）。
- 关闭面板：点空白处或系统返回，回到场景，不重新打开抽屉。

## 8. 新手引导（guide/）
- **触发：** 首次启动，加载完成后直接进入 3D，`wx.getStorageSync('fw_guide_v1')` 为空时开始引导。完成或跳过都写 `wx.setStorageSync('fw_guide_v1','done'|'skipped')`。之后可以在「玩法」里重看。
- **1/3：** 椭圆 guide_ring 套住木头（只有这一步用椭圆），可以正常交互。第一次劈开成功后等 600ms，进入下一步。
- **2/3：** 只用圆角矩形框住小签（外扩 4pt，r12，2pt 奶油描边），尾巴朝上指向小签，下方写「轻点任意处继续」。点小签也算继续。
- **3/3：** 自动把抽屉展开（按 §5 的动效），框住「免费领取」主钮和「风格」行两处，各自一个圆角矩形。气泡在抽屉下方，尾巴朝上；皮革钮「知道了，开砍！」紧贴在气泡下方 12pt。点它或点任意处，抽屉收起，引导完成。
- **全程：**
  - 底部中间显示「跳过 〉」（84×32 @ y712）。
  - 小签不隐藏。
  - 标题 serif 16pt 左对齐，正文 sans 12pt 左对齐，步骤号 n/3 在气泡右上角 11pt。
  - 遮罩 58%（第 3 步 50%）。
  - 引导期间不弹用尽面板，排队到引导结束后再弹。开局剩余为 0 时，直接从第 2 步开始。
- **埋点：** `guide_step_view{step}`、`guide_complete`、`guide_skip{step}`、`drawer_open{src:tap|drag|guide}`。
